# Agent v0.10.4

与主控 v0.14.0 配合启用本地设备准入复用：同一授权、节点、规范化来源 IP 的并发连接共享远程请求，允许结果最多复用 1 秒。授权从请求开始计时，不因命中延长；到期、撤销、通道异常会限制或清除授权。拒绝与错误不缓存。

不增加 Redis 等独立缓存服务，保留原有设备限制、流量计量与授权控制。旧主控没有租期和授权版本信息时不启用允许结果缓存。

请先升级主控 v0.14.0，再在服务器管理中更新 agent。内核保持 sing-box 1.14.4-yjunit.5 和 Xray 26.10.29-yjunit.1，维护服务 0.12.1。升级保留节点配置、凭据和累计流量日志。

提供 amd64 / arm64 包，保留代理内核对应源码、构建元数据及许可。主控二进制由独立的 YJVIst/YJunit 仓库提供。
